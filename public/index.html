Pertanyaan Umum

Temukan jawaban untuk pertanyaan yang sering ditanyakan

Apa itu Dramoo API? +
Dramoo API adalah platform aggregator yang menyediakan akses ke 38+ platform drama pendek Asia melalui satu API terpusat. Anda bisa mencari, menonton, dan mengakses konten dari DramaBox, ReelShort, MicroDrama, dan banyak lagi.
Bagaimana cara mendapatkan API key? +
Anda bisa mendapatkan API key melalui Telegram Bot kami di @dramoobot. Pilih paket, bayar, dan API key akan otomatis dikirimkan ke Telegram Anda.
Apa perbedaan antar paket? +
Setiap paket memiliki jumlah platform yang bisa diakses, limit request harian, dan durasi yang berbeda. Paket Starter cocok untuk pemula (12 platform), sedangkan Ultimate memberikan akses ke semua 37+ platform.
Apakah ada rate limiting? +
Ya, setiap paket memiliki limit request harian. Selain itu ada limit global 1000 request per menit per IP/key. Limit harian akan reset otomatis setiap tengah malam (WIB).
Bagaimana cara menggunakan scraper endpoint? +
Endpoint scraper tersedia di /scrape/. Anda bisa mencari drama, melihat detail, dan mendapatkan URL streaming. Semua endpoint scraper membutuhkan API key yang valid. Platform yang didukung: melolo, dramawave, pinedrama, dramabox.
API key saya tidak berfungsi? +
Pastikan API key Anda belum kadaluarsa dan masih aktif. Anda bisa menggunakan fitur "Cek API Key" di atas untuk memeriksa status key Anda. Jika ada masalah, hubungi admin melalui Telegram.
