Admin API Documentation

Gunakan endpoint ini untuk mengatur API secara terprogram (via sistem lain). Semua request wajib menyertakan header X-Master-Key.

GET /admin/stats

Mendapatkan data analitik, statistik pengguna, statistik API key, dan performa paket.

POST /admin/keys

Membuat API key baru secara manual.

Body: { "telegram_id": "123", "username": "...", "full_name": "...", "package_id": "standard", "note": "..." }
PATCH /admin/keys/:id/status

Mengubah status API key.

Body: { "status": "active" | "suspended" | "revoked" }
DELETE /admin/keys/:id

Menghapus API key secara permanen dari database.

PATCH /admin/platforms/:id

Memperbarui status platform atau URL API-nya.

Body: { "status": "active" | "maintenance" | "coming_soon", "api_url": "..." }
